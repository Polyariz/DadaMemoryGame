  - Вызывает `notifyListeners()`

- ✅ `closeAllCards()` - Сброс всех карт
  - Все карты: `isOpen = false`, `isFind = false`

- ✅ `reloadGame()` - Перезапуск игры
  - Перемешивает карты
  - Сбрасывает счет до 200
  - Сбрасывает `found` до 0

- ✅ `isGameFinished` - Геттер проверки победы
  - Возвращает `found == 15`
