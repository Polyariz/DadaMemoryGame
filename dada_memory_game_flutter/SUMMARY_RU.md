## 🚀 Как использовать

### 1. Установка

```bash
cd dada_memory_game_flutter
flutter pub get
```

### 2. Запуск в VS Code

1. Откройте папку `dada_memory_game_flutter` в VS Code
2. Убедитесь, что установлено расширение **Flutter**
3. Выберите устройство (эмулятор/физическое)
4. Нажмите **F5** для запуска

### 3. Запуск из терминала

```bash
# Просмотр доступных устройств
flutter devices

# Запуск на устройстве
flutter run

# Релиз режим (быстрее)
flutter run --release
```

### 4. Сборка для релиза

```bash
# Android APK
flutter build apk --release

# Android App Bundle (Google Play)
flutter build appbundle --release

# iOS (только macOS)
flutter build ios --release
```

## 🎮 Как играть

1. **Запуск**: При первом запуске введите ваше имя
2. **Игра**: Нажимайте на карты, находите пары
3. **Очки**:
   - Начальный счет: 200
   - Совпадение: +50
   - Ошибка: -10
4. **Победа**: Найдите все 15 пар
5. **Результат**: Посмотрите таблицу лидеров
6. **Повтор**: Нажмите "Играть снова"

## ✨ Ключевые особенности

### 1. Анимация переворота карт

Использует Flutter `Transform` с `Matrix4.rotationY` для создания 3D эффекта переворота карты, идентичного оригинальному CSS transform.

### 2. Firebase Realtime Database

Полная интеграция с той же Firebase БД, что и оригинал. Результаты сохраняются в реальном времени и видны на обеих версиях (React и Flutter).

### 3. Адаптивный дизайн

Автоматически подстраивается под размер экрана:
- Desktop: 5 карт в ряду
- Mobile: 5 карт в ряду (меньший размер)

### 4. Производительность

- Минимальные перерисовки благодаря Provider
- Const конструкторы где возможно
- Оптимизированные изображения
